# Hi, I'm Daniel 👋

### Technical SEO Specialist · SEO Analyst · AI Search Optimization (AEO/GEO) · Web Developer

I come from web development, so I do SEO from inside the code. When a site isn't getting indexed, loads slowly or is losing traffic, I trace the problem to its root cause in the codebase, fix it, and ship the change through Git alongside the dev team.

📍 Argentina · Remote · 🇪🇸 Spanish (native) · 🇬🇧 English

---

## 🔧 What I work on

- **Technical SEO:** crawling, indexing, site architecture, internal linking, canonicals, redirects, structured data
- **Web performance:** Core Web Vitals, Lighthouse, PageSpeed Insights and Chrome UX Report, fixed directly in the code
- **International SEO:** hreflang, multilingual routing, locale handling in Next.js & Astro.js
- **AI Search (AEO/GEO):** structured data, entities and content that AI Overviews, ChatGPT and Perplexity can cite
- **SEO automation:** n8n workflows, Claude Code, AI agents and MCP servers for audits, research and bulk changes
